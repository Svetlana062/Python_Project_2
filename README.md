# Проект 2. Поиск вакансий

## Описание проекта
Данная программа будет получать информацию о вакансиях с платформы hh.ru в России, 
сохранять ее в файл и позволять удобно работать с ней: добавлять, фильтровать, удалять.

## Требования к окружению
Python 3.13+

## Установка
* Клонируйте репозиторий:
```
git clone https://github.com/Svetlana062/Python_Project_2.git
```
* Установите зависимости:
```
pip install -r requirements.txt
```
* В случае отсутствия менеджера проектов _poetry_, выполните установку пакетов:
```
poetry install
```
* Войдите в виртуальное окружение:
```
poetry shell
```

## Использование
Данная программа получает информацию о вакансиях с платформы hh.ru в России, 
сохраняет ее в файл и позволяет удобно работать с ней: добавлять, фильтровать, удалять.

Чтобы начать тестирование, необходимо, через терминал, установить pytest:

## Структура проекта
Проект содержит абстрактные классы и классы для работы с API платформой с вакансиями:

* data/vacancies.json - файл, в который по умолчанию сохраняются данные с найденными
вакансиями;
* src/abstract_class_api.py - данный модуль содержит абстрактный класс для работы с API 
сервиса с вакансиями;
* src/abstract_file_handler.py - данный модуль содержит абстрактный класс, который 
обязывает реализовать методы для добавления вакансий в файл, получения данных из файла 
по указанным критериям и удаления информации о вакансиях;
* src/hhru_api.py - данный модуль содержит класс, наследующийся от абстрактного класса, 
для работы с платформой hh.ru. Класс умеет подключаться к API и получать вакансии;
* src/json_file_handler.py - данный модуль содержит класс для сохранения информации о 
вакансиях в JSON-файл;
* src/user_interface.py - данный модуль содержит функцию для взаимодействия с пользователем.
Функция взаимодействует с пользователем через консоль; 
* src/vacancy.py - данный модуль содержит класс для работы с вакансиями. В этом классе 
определены атрибуты (title: название вакансии, url: ссылка на вакансию, salary: зарплата, 
description: краткое описание). Класс поддерживает методы сравнения вакансий между собой
по зарплате (__lt__);
* main.py - модуль для запуска основного функционала программы.
